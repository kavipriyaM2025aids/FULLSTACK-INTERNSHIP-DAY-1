

# Kavipriya's Resume Website

A personal resume website developed using HTML, CSS, and JavaScript to showcase my education, internships, technical skills, projects, achievements, certifications, and coding profiles.

## About the Project

This project is a personal resume website designed with a clean layout, simple navigation-free design, and a soft mauve color theme. It presents my academic background, technical experience, and projects in an organized format.

## Features

- Clean and simple resume layout
- Soft mauve background theme
- Full-width header section
- Personal details and social profile links
- Education details
- Internship experiences
- Technical skills
- Projects
- Achievements and certifications
- Coding profiles
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Sections

- Profile
- Education
- Internship Experiences
- Skills
- Projects
- Achievements
- Certifications
- Coding Profiles
- Contact
